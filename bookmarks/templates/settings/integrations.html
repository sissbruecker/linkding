{% translate "Feed URLs support the following URL parameters:" %}

  • {% blocktranslate trimmed %} A limit parameter for specifying the maximum number of bookmarks to include in the feed. By default, only the latest 100 matching bookmarks are included. {% endblocktranslate %}
  • {% blocktranslate trimmed %} A q URL parameter for specifying a search query. You can get an example by doing a search in the bookmarks view and then copying the parameter from the URL. {% endblocktranslate %}
  • {% blocktranslate trimmed %} An unread parameter for filtering for unread or read bookmarks. Use yes for unread bookmarks and no for read bookmarks. {% endblocktranslate %}
  • {% blocktranslate trimmed %} A shared parameter for filtering for shared or unshared bookmarks. Use yes for shared bookmarks and no for unshared bookmarks. {% endblocktranslate %}
  • {% blocktranslate trimmed %} A user parameter for filtering bookmarks by user name. Only applies to the shared bookmark feeds. {% endblocktranslate %}
